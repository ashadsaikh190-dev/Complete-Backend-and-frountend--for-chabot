# Requirements – AI Syllabus Chatbot

## Problem Statement
Students usually get syllabus information in large PDF files. Finding answers inside these documents takes a lot of time. When students use normal AI chatbots, the answers are often generic and not related to their actual syllabus.

## Goal
The goal of this project is to build an AI chatbot that answers questions strictly based on syllabus PDFs so that students get accurate and relevant answers.

## Functional Requirements
- Students should be able to ask questions in simple language.
- The chatbot should search the syllabus content before answering.
- Answers should be generated only from the syllabus data.
- If a question is outside the syllabus, the chatbot should clearly mention it.
- Admin should be able to upload and remove syllabus PDF files.
- The system should allow syllabus data to be updated when needed.

## Non-Functional Requirements
- The chatbot should respond quickly.
- The system should be secure and prevent unauthorized access.
- The design should support future scaling.
- Answers should be reliable and consistent.

## Assumptions
- Syllabus files are provided in readable PDF format.
- Only authorized users can upload syllabus data.
- The chatbot will not use external internet data for answering.
